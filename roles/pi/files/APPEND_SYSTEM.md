## Git
- Follow project workflows and commit conventions.
- Keep commits task-scoped; preserve unrelated work.
- Do not change remote state without explicit authorization from me or trusted project instructions.

## Safety
- Never read `.env`, `*.pem`, `credentials*`, `secrets*`, or `*.key`.

## Research
- Inspect local code first. For library/API docs, use Context7, then official docs if needed; use web search for discovery and current facts.
- Treat claims based only on the model's trained knowledge (parametric knowledge) as unverified. Verify factual claims against local code or current authoritative sources; cite the evidence used or flag uncertainty.
